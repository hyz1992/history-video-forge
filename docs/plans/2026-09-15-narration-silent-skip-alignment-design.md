# 口播归一化有限编辑容错对齐设计

适用项目：`history-video-forge`
日期：2026-09-15
关联：`backend/src/modules/narration/narration-timing-normalizer.ts`、`shared/src/narration/narration-timing.schema.ts`、[口播前置设计](./2026-09-05-narration-first-timing-design.md) §5.1（token 映射与「不明确映射报 narration_timing_invalid」）

---

## 背景与问题

口播时间轴校验要求供应商原生句子与原文精确映射。供应商会对原文做**字形层改写**，我们以白名单枚举应对，但每次遇到未知变体都整篇失败、白付一次付费调用：

| 日期 | 变体 | 处理 |
|---|---|---|
| 2026-09-11 | `〇` → `零` | 白名单补候选 |
| 2026-09-12 | `𠮷` → `吉` | 白名单补候选 |
| 2026-09-15 | `——` → `，` | 白名单补候选 |
| 2026-09-15 | `——` → `—`（每处 -1 字） | 白名单补候选（本次已修） |

实测证据：470 字文案、三处 `——`、诊断 `normLenDiff: [-3]`。**这一类改写（供应商吞掉标点/空白）在合同上本来就是允许的**——`shared/src/narration/narration-timing.schema.ts:73` 的覆盖检查只要求"source 中未被 token 覆盖的区间必须是静音（`\p{P}\p{Z}\s`）"，即标点/空白本就不需要被发音覆盖。当前失败的唯一原因是 **候选枚举 DP 只会"原样匹配或白名单变换"，没有"跳过静音"这条对齐路径**。

## 设计

`mapSentence` 的 DP 增加一条转移：**跳过静音 grapheme**。

1. **仅允许跳过静音**：block 对应内容满足 `/^[\p{P}\p{Z}\s]*$/u` 时才生成 skip 转移。汉字、字母、数字**不可跳过**——供应商吞正文时仍按失败处理（不掩盖真实漏读）。安全边界与 schema 覆盖检查同源，不新增合同。被跳过的静音**不被任何 token 覆盖**（留下静音空档），合法性来自 `narration-timing.schema.ts:69` 的"未覆盖区间只要静音即可"，不是"token 区间跨过标点"。
   注：`SILENT_PATTERN` 是与 shared `silent` 字面量同源的本地副本（shared 未导出该谓词）。本地更严（少跳）只会更保守，本地更宽（多跳）由 schema 覆盖检查兜底拒绝，故当前无行为分歧；若 shared 收窄该字符类，需同步本地副本。
2. **白名单优先 + 重复静音折叠**：match 转移成本 0（含白名单变换与折叠候选），skip 转移成本 = 被跳过 block 的 code unit 数（`——` 记 2；数字 block 非静音、不可跳过，故不参与记账）。因此已知变体与折叠变体永远优先；skip 只在无零成本路径时启用，只作为**未知静音改写的兜底**。
   **折叠候选**：连续相同的静音字符（`——`、`……`、`！！`、换行）合并为一个原子 block，候选为 [原样, 折叠为单个]；CRLF 另有 LF 候选（`
` 归一为 `
` 的相邻形态）。供应商把重复标点读成单个（`……`→`…`、`！！`→`！`、`\n\n`→`\n`）因此获得**确定性**映射（整个 run 由单个字符代表），不落入"歧义必拒"——这是对歧义语义的定向收窄：原本两个换行读成一个有两条解析路径（保留哪一个），现在收敛为一条明确的折叠路径。覆盖范围因此含两类：**静音删除**（skip）与**重复静音折叠**（折叠候选）；非重复的静音**替换**（如 `。`→`；`）仍失败，由白名单机制承担。
3. **唯一最优**：目标状态必须存在且最小成本路径唯一；多路径同成本仍 fail-closed（保持既有"不允许歧义"语义）。实现上必须**排空全部成本 ≤ 最优成本的节点**后才判定——目标态 settle 后仍可能被同成本路径重复到达；提前返回会漏掉该标记（基线逐层 DP 无此窗口，首轮实现曾因此回归，见验证节）。push 时若目标键已 settled 且同成本，当场标记歧义而非去重丢弃。
4. **normalized 必须完整覆盖**：插入/替换类未知变体不被容忍（normalized 字符必须全部被 match 消耗）。理由：`TimingToken` schema 要求 `sourceEnd > sourceStart`，无 source 归属的插入字符无法诚实映射；替换继续由白名单机制负责（补一条候选成本极低）。
5. **预算**：skip 成本上界天然 = 静音 code unit 总数（只有静音可跳），实现取 `min(silentTotal, 256)`，只用于防 DP 状态爆炸；不承担安全职责（安全由"仅静音"保证）。当最优对齐需要跳过的静音量超过 256 时 fail-closed 并输出 `kind: "skip_budget"` 诊断（注意：这是"曾发生截断"的标记，属可能原因而非因果归因；纯静音且无需超出预算的输入不受影响）。
6. **诊断**：发生跳过时 `console.warn` 输出被跳过的 source 片段（取文中最靠前的 8 条），便于观察供应商行为；不新增 shared schema 字段。
7. **搜索实现**：成本分层 Dijkstra（buckets 按成本分层，match 成本 0 优先扩展），状态 `(blockIndex, normalizedOffset)` 经 `settled` 去重。状态保护两层（均为防御性：折叠候选消除零进度前沿的大规模来源后，构造上极难触顶）：
   - **逐层上限 4096**（与基线 `next.size > 4096` 同构；全局上限可能先触顶，见下）；
   - **全局上限 2,000,000**（只防无界增长，不构成内存优化）。
   触顶时 fail-closed 并输出 `narration-align-limit` 诊断。可达性：`skip_budget` 可达（有用例）；`state_limit` / `layer_limit` 为防御性分支——单层 offset 差受 `budget ≤ 256` 约束（数字候选长度差是唯一额外来源），故单层状态数远低于逐层上限 4096，两者在实际输入下均未触发。
   实测边界（一次性探针，未入库）：单句 631/1500 个连续换行与基线同为 ACCEPT；**临界点为 1999**（K≥1999 由全局上限拦下，诊断 `state_limit`），基线临界点为 4095（其逐层上限）。即 **[1999, 4095] 区间本实现比基线更早 fail-closed**：基线以约 485MB 堆为代价接受，本实现接受到 K=1998 时堆约 759MB。触发需"单句约 2000+ 连续静音 block"，真实文案（句内换行为个位数）差约 3 个数量级；方向 fail-closed，不影响正确性。

> 2026-09-16 更新（[静音受控替换](./2026-09-16-narration-silent-replacement-design.md)）：因新增替换转移，DP 成本上界改为 `min(silentTotal, 256) + min(silentBlocks, 256)`（≤512），本节此前记录的 256 上界与实测临界点按新上界失效；替换候选均为单字符，分支度基本不变。

## 明确不改

- shared schema（`silent` 覆盖规则、token 非零宽约束均不变）；
- 白名单候选机制（保留为首选路径，继续覆盖替换类变体）；
- WS 协议、投影/吸附/重生、分镜与下游；
- 不引入编辑距离式的"任意增删替换"——只增加"跳过静音"一条路径。

## 验证

- 单测：静音跳过对齐（句号/顿号/引号/括号被吞、整块 `——` 被吞——即白名单无法匹配时由 skip 兜底）；重复静音折叠（`……`/`！！`/`？？`/`。。。`/两个换行 → 单字符，断言 token 区间覆盖整个 run）；汉字与数字被吞仍拒绝；诊断 payload 记录被跳过片段而非正文；静音量超上限输出 `skip_budget` 诊断；白名单与跳过竞争时取成本 0 路径；病态超长输入有界失败；原样与白名单路径回归。
- 语义演进（本轮）：原本按"歧义"拒绝的"两个换行读成一个"等输入，因折叠候选获得确定性映射而变为接受（既有对抗用例已相应更新为断言折叠确定性）。
- 真实工件（一次性探针，未入库）：470 字实测文案 + 三处 `——` 被读成 `—` 的优先路径 27ms 通过；46 个标点全被吞（白名单完全未覆盖）10ms 通过；吞一个正文汉字拒绝。对应的常驻回归为合成等价场景（470 字 42 逗号、整块 `——` 被吞）。
- 性能：470 字文案对齐耗时在毫秒级（DP 状态受预算约束）。
- 审查：T2（时间轴核心合同），diff_reviewer + contract_reviewer → final_reviewer R5 两阶段。
