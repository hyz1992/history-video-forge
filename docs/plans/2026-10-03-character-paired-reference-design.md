# 同规划身份与定妆图配套验收设计

## 任务、证据与目标

沿用用户角色一致性验收、整改与继续授权，原 50 元预算累计估算 3.967263 元，实账未核对。本次只解决稳定身份字段边界并验收同一规划内的两角色、两目标镜，不扩展跨规划保脸功能。

上轮完整新 global 与旧 H2/E2 不相容，按既有小批停止，记录不覆盖。代码进一步核对：`asset-plan-intent-compiler.ts` 从同一 global 的角色生成 sheet task 与身份锚点，`character-sheet-reference.ts` 按 sheet task 的 character_id 与 artifact metadata 查找参考。因此新 global 与旧人工 QA 身份的差异，是配套验收选择的问题，不能直接视为同一新规划内的一致性失败。旧参考仍不适合强行注入新方案。

另一个真实缺口是 identity 夹杂神态、姿态、能力与行动描述。现有规则埋在全局身份长段中。将该规则独立为短列表，保留主叙事时点年龄要求，明确 identity 仅稳定身体特征，神态、姿态、气质与能力放到 visual_description。只改正式中文 planner，不做本地语义字符串判断、输出删词或自动语义修复。

## 方案与边界

推荐先回修一条 prompt，再在同一新 global 下真实生成两个目标分块和配套定妆图。替代方案是新增既有身份复用输入合同，范围更大且用户原始要求未指定跨重新规划保脸；手工改新输出迎合旧参考会掩盖真实链路。本次不采用这两种方案。

正式变化仅全局 planner v1.6.0、中文 changelog 和既有合同测试。segment v1.5.0、优化器、schema、编译器、模型、原 18 段 storyboard/script/topic/口播/双快照路线/画风/720P 不变。角色 ID 与体型可由新模型确定，完整 global 人工合格后冻结；不要求与旧人工身份或旧图片相同，也不宣称所有历史外貌细节有史料保证。

## 有界规划验证

新 `scene-planner-paired-*` 文件保留独立来源和成本基线，旧 repair/capacity 两批的取消和失败证据不可覆盖。最多新 global、chunk_002、chunk_006 三次真实调用，每次 maxAttempts=1、maxTokens=16384、timeoutMs=120000，完整系统加输入不超过 50000 bytes，串行。拒绝结构修复或第四次；任一失败停止，不自动下一轮改稿。

先只请求 global，人工核对完整 JSON、主时点年龄阶段、稳定身体特征与造型分工。这里的人工批准只允许继续目标文本调用，不是旧 H2/E2 相容批准，更不是整片通过。若身份边界仍不合格，停止本批。

global 合格后才请求两个目标块；其余四块明确重放旧七次的原始解析输出，只证明结构与编排，不证明全片语义。真实 compiler 和 local validator 通过后，人工检查 sb_004 宫门紧闭、李世民手按佩刀与门的关系、可见甲胄结构；sb_016 冕板珠旒礼服结构、正在登上御座的瞬间、李渊退居一侧与百官职责，不补额外关键人物。未合格不激活或生图。

## 配套图片验证

仅在文本合格后，另存独立 QA plan/manifest。全局角色身份原文、两角色 compiler sheet prompt、两目标 compiler 已 enrichment 的 prompt 原样冻结，不二次 enrichment，不把旧参考改 metadata 冒充新角色。其他任务沿用 QA 历史选中件且明确它们不是同一新 global 的整片验收；新 global 本身保留完整原文作为来源。

新增两张同方案的李世民/李渊定妆图，单人写实全身、无兵器、中性服饰、2048×1152；逐张内置浏览器单次生成、目视核对新身份。合格后冻结两图 artifact/hash，分别用于甲胄镜与两人登御座镜，1080×1920。两镜各一次，身份、衣冠、原动作、人数、空间职责全部检查。任何失败停止该小批，不重复抽图；失败后的剩余图取消。

只允许四个目标任务的选中产物更新；新 sheet artifact 必须带本方案 character_id，实际 request 参考 bytes/hash 与选中图片一致，sheet 不进 segment route，每图 n=1、wan2.7-image、一次提交/一次 usage。QA DB 写入需停止自有 3009 后端；历史 plan/manifest 正文和生产 DB 不变。只读检查与界面截图保存本地，生成态不提交。

## 预算、验收与风险

既有九次 LLM 2.167263 元＋九图 1.80 元继续累计。新 LLM 单次最坏预留 0.901584，三次 2.704752，仍落在原 8 元 LLM 预留内；新四图 0.80 元，累计最坏 **7.472015 元**，不超过原 50 元。最多累计十二次 LLM、十三张图，视频 0。调用前记录费用预留，缺 usage 不记零；所有实际账单未核验。

验收矩阵区分规则合同、global 身份、两目标文本、配套参考、两镜画面与全片。全片与统计稳定性未验证，不因四旧块回放或有限两图成功扩大范围。仍可能模型输出不遵守身份规则，或出图不遵守动作/人数；失败保留并报告，不把预算当重试目标。
