# 玄奘题材 Flash 模型同输入质量对照

## 结论

两次有界真实调用已完成。Flash 分镜通过正式结构及真实时间轴校验，但没有解决用户指出的行李、光鲜衣着与身体困顿问题，还保留明显的口播与画面事件错位；Flash 文案未通过本地体量下限。本轮不采用新稿、不激活新分镜，也不进入素材生成。

本次证据支持“只换模型不足以修复本题视觉问题”。不支持“Flash 普遍比 Pro 差”，也不能证明某款更贵模型必然解决问题。后续应先修复既有规划层的状态表达和验收要求。

## 系统层面的定位

1. **规划缺少可执行的身体和行旅状态。** 原全局美术输出将玄奘描述为“年轻光头僧人”“灰褐色唐代交领僧衣”“外披风化粗布”“神态凝重而坚毅”，核心道具只有水囊、瘦老赤马和缰绳，未建立行旅负载。电影级光影和凝重神情可以改善气氛，却没有表达衣物磨损、重心、步态、失水程度和恢复过程。原片 `final-contact-2.jpg` 的 24.36–51.44 秒抽帧中，人脸、衣物仍整洁，身姿较稳，未见明显旅行负载；这与用户的视觉批评相符。抽帧检查不代表本轮重新完整审看了视频。
2. **已有衣冠规则还没有覆盖状态变化。** 正式全局 prompt 已区分稳定 `identity_description` 与场景 `visual_description`；分段 prompt v1.6.0 已要求主角服装、具体衣冠结构、连续动作和道具相对关系。不能误称系统完全没有服装/动作约束。缺口是这些内容如何随旅程与事件持续变化，以及如何在每个分块中被消费；不能把临时脏污、疲惫写进永久身份锚点。
3. **时间来源一致与语义对应是两项验收。** `storyboard-timing-projector.ts` 校验边界、连续性、原文和毫秒的同源派生；候选切点由句末或 ≥400ms 间隔粗筛。候选合法不保证选择的边界具有自然语义，也不保证 `scene_description` 在描写当前段的动作。新分镜通过真实投影，但仍发生拆名和结果提前。
4. **人工验收也遗漏了核心体验。** 原样片经过人工提示修订和素材检查后仍呈现用户指出的问题，说明当时验收过于关注同人、时代、无乱码和生成成功，没有充分检查“是否像一个正遭受失水的长途旅人”。不能只把责任归给一次 LLM 输出或视频模型。

证据范围：本轮只真实调用 writer 与 storyboard planner；没有对 Flash asset planner、图片模型或 H3 生成表现做新实验。上面的规划层定位基于既有正式 prompt、原 asset planning 输出、新分镜和旧片抽帧，不是供应商模型故障归因。

## 后续最小改动方向（尚未实施）

按低耦合任务拆开，先写中文设计与实施计划，再改正式 prompt 或 shared 合同：

1. **先收敛分镜语义对应。** 在既有 storyboard planner 规则中明确当前口播事件、动作起止和结果首次出现的关系；根据正文选择自然的语义边界，不能仅因切点合法就拆开称谓或把结局提前。仍由 LLM 做语义选择，本地继续只验证结构和时间合同，不加人名关键词黑名单。
2. **补全状态表达和跨段传递。** 在既有全局美术及分段规划职责中明确：稳定身份保持，随事件变化的衣着磨损、身体姿态、携带物及人/物相对位置另行规划；分块必须消费同一份全片状态安排。优先评估能否用现有 `consistency_notes`、全局说明和分镜描述表达；确需新结构时再修改合同，不能无设计扩 schema。
3. **明确合理还原的边界。** 史实叙事仍以已确认脚本为准。旅途负载、衣物积尘等场景细节应标明是合理视觉推断，不能编造史料未证的具体装备、数量或行为；不固定所有角色“越脏越好”，由场景事件决定。失水后喝水不能立即把衣物和身体状态重置为光鲜。
4. **素材投入前做有限质量验收。** 首先人工看规划是否表达了负载、磨损、困顿和当前事件，再选关键镜头的少量锚点图看这些证据是否可见。没有可见证据时不进入全片视频；保留 reviewer 的 shadow-only 边界，不新增自动语义门禁、重写阶段或无限返工。

建议优先级：分镜语义对应 → 全局状态与分块消费 → 关键锚点图 → 视频。此次结果不支持继续仅靠换模型重拍全片。
