## 结论

本轮改动没有破坏结构链路，且晏子样本的故事完整性明显恢复：两轮都讲到了狗门羞辱、使狗国者从狗门入、橘生淮南淮北。开头也基本都有面向观众的反问或强判断，能更快把人拉进冲突。

但“必讲节点合同”只产生了有限改善。`must_include_beats` 仍常混入解释性评价和结果总结，writer 仍会在正文里复述这些字段。下一步不宜继续堆 writer prompt，而应审计 topic candidate-builder 的输入样例、候选选择和 `must_cover_preview` 生成压力，判断是否需要把节点形态从 prompt 文本约束提升到更明确的上游候选输出训练样式或样例约束。这个方向有效但不充分，不能宣称已经解决字段痕迹问题。
