# 完成定义（Definition of Done）

适用范围：`story-video-forge2` 当前的 harness、topic、script 相关工作

## 一次任务被视为完成，至少满足：

1. 范围清楚
   - 明确改哪些文件
   - 明确不改什么

2. 改动完成
   - 所承诺的文件已修改或创建

3. 验证完成
   - 跑过本任务对应的最小验证
   - 没有把“应该验证”留到下次

4. 文档同步完成
   - 如果改动影响 schema / API / rules / prompt / plan，必须同步相应文档

5. 自审完成
   - 明确写出剩余风险
   - 不把未解决问题伪装成完成

6. 提交完成（如本轮要求提交）
   - 提交信息使用中文
   - 一次提交只解决一个清晰问题

## 当前特别强调

- 没有验证，不得声称完成
- 没有文档同步，不算真正完成
- 业务实现前，harness 与设计边界必须先站稳
